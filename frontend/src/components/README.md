# Components Directory

This directory contains reusable React components used across the application.

## Structure

- **common/**: Shared components used throughout the app (buttons, inputs, cards, etc.)
- **consumer/**: Components specific to the Consumer Portal
- **distributor/**: Components specific to the Distributor Portal
- **owner/**: Components specific to the Owner Dashboard
- **layout/**: Layout components (header, footer, navigation, etc.)

## Guidelines

- Each component should be in its own directory with an index.tsx file
- Include component-specific styles in the same directory
- Export components from index.tsx for clean imports
